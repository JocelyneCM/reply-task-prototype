About Relay

Relay is the prototype used for the study. Participants complete short reply tasks in SMS, Messenger, or Email style interfaces.

The system records each reply with timing and writing behaviour data, such as response time, input method, keystrokes, backspaces, paste use, and corrections.

The main style/register signal is the trained formality model stored in formality_model/. Its output is saved as formality_label and formality_confidence.

BERT sentiment is still available in the data, but it is secondary and should not be treated as the main formality result.

Audio replies can be transcribed with Whisper when transcription is available. Uploaded prompt audio is not transcribed.

The main study exports are saved under prototype/data/logs/ and participant-specific folders.

Formality model notes

  • formality_model/ — active trained model files (replace when Jakob shares an updated checkpoint).
  • prototype/utils/formality_service.py — loads the model for inference.
  • prototype/utils/analysis_utils.py — combines formality output with other analysis fields before logging.
  • If the model or label set changes, check the label mapping before interpreting LABEL_0 / LABEL_1 (see model config or training notes).

Writing behaviour metrics by input method

  • response_time_seconds — the main comparable timing metric across all input methods. Measured from prompt display (or first keydown for typing) until Send is pressed.
  • Typing — keystrokes and backspaces are literal keyboard events (keydown). Timing starts at the first key press.
  • Swipe typing — the browser may report synthetic keydown events for each inserted character. Keystroke and backspace counts are approximate interaction/editing events, not exact physical key presses or swipe gestures.
  • Voice-to-text — keystrokes are 0 unless the participant manually edits the transcript after dictation. Timing runs from prompt display to Send press, covering the full dictation and review interval.
  • words_per_minute — computed server-side from word count and response_time_seconds. Comparable across methods only if response_time is interpreted correctly.
