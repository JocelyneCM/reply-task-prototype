How Relay logging works

  • Each participant reply is saved with time, channel, response text (or transcript), and behavior metrics.
  • Voice replies can be transcribed when transcription support is available on the server.
  • This admin console reads the saved data and shows summaries, trial details, and analysis in one place.
  • Exports download the same CSV files used by this dashboard.
